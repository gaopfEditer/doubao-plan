# 项目05 · Agent 使用

> **项目定位：** 以 Grok Bot 为主要Agent工具，拆解 ChatGPT 的设计思路，刻意练习叙述场景表达能力。

## 项目概述

系统提升对 AI Agent 工具的使用能力。当前以 Grok Bot 为主力工具，同时深入拆解 ChatGPT 的产品设计思路（交互逻辑、提示词工程、场景化表达），反向学习如何更好地与Agent协作。核心训练方向：把模糊想法转化为清晰的场景化叙述，让Agent能准确理解意图并产出高质量结果。

## 核心任务

| 任务模块 | 具体内容 | 目标 |
|---|---|---|
| **Grok Bot 实战** | 日常工作流接入Grok，覆盖信息整理、内容生成、代码辅助等场景 | 形成稳定的使用习惯 |
| **ChatGPT 拆解** | 分析ChatGPT的产品设计：对话流程、系统提示词思路、功能模块设计 | 提炼可复用的设计原则 |
| **场景表达训练** | 练习把需求写成清晰的场景描述：背景、目标、约束、输出格式 | 提升Prompt成功率 |

## 关键动作

1. 梳理日常工作中可被Agent替代/加速的环节，逐步接入Grok Bot
2. 每周拆解一个ChatGPT的功能或对话案例，分析其设计逻辑
3. 建立个人Prompt模板库：按场景分类（写作、分析、代码、总结等）
4. 每次Agent输出不理想时，复盘是意图不清还是表达不够具体
