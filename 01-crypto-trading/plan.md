# 项目01 · 币圈操盘计划

> **项目定位：** 每日定时监控币圈行情数据，结合技术形态执行小止损交易策略，晚间持续学习威科夫方法论与微操技巧。

## 项目概述

围绕加密货币交易，建立系统化的每日盯盘与交易流程。通过自动化定时获取核心数据（涨跌幅、日报、榜单、解锁、OI持仓量），结合价格形态识别入场与出场点，严格执行小止损纪律。同时利用晚间时间深度学习威科夫交易理论与微观操作技巧，持续提升交易胜率。

## 核心任务

| 任务模块 | 具体内容 | 频率 |
|---|---|---|
| **行情监控** | 涨跌幅监控、每日行情日报、币种榜单、代币解锁日历、OI持仓量变化 | 每日定时 |
| **交易执行** | 形态识别入场、小止损设置、仓位管理、止盈纪律 | 交易日 |
| **学习提升** | 威科夫方法论学习、微操技巧练习、复盘交易案例 | 每晚 |

## 关键动作

1. 搭建定时监控脚本/工具，自动抓取涨跌幅、解锁、OI等数据并推送
2. 建立每日交易流程：盘前准备 → 形态识别 → 入场 → 止损/止盈 → 盘后记录
3. 制定威科夫学习计划：分阶段研读理论，结合历史K线图练习
4. 建立交易日志，记录每笔交易的入场理由、止损位、结果与反思
