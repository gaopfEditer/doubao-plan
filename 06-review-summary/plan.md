# 项目06 · 复盘总结

> **项目定位：** 定期回顾过往灵感与走歪的方向，提炼经验教训，避免重复踩坑，沉淀可复用的方法论。

## 项目概述

建立系统化的复盘机制，定期回顾历史上的灵感记录、项目尝试和走弯路的经历。核心目的不是简单回忆，而是从中提炼规律：哪些方向做对了、哪些是无效投入、哪些灵感被浪费了。通过持续复盘，减少重复试错成本，让经验真正转化为判断力。

## 核心任务

| 复盘维度 | 具体内容 | 频率 |
|---|---|---|
| **灵感回顾** | 翻出历史灵感笔记，评估哪些仍有价值、哪些已过时、哪些被遗漏了 | 每月 |
| **走歪复盘** | 回顾投入了但没产出的方向，分析为什么走偏、何时该止损 | 每季度 |
| **经验沉淀** | 把复盘结论整理成可复用的原则、检查清单或决策框架 | 持续 |

## 关键动作

1. 整理所有历史灵感/想法的记录渠道（备忘录、聊天记录、笔记等），汇总到一处
2. 建立复盘模板：事件回顾 → 当时判断 → 实际结果 → 差异原因 → 下次怎么做
3. 每月固定时间做一次灵感盘点，标记"值得重启""已放弃""继续观望"三类
4. 每季度做一次大复盘，提炼3-5条最重要的经验教训
