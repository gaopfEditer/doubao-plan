# 项目07 · 工具建设

> **项目定位：** 完善 autoscript 与 python-ai-operate 工具链；makemoney 项目待启动；评估引入 Hermes 工具。

## 项目概述

构建个人效率工具栈，把重复性工作自动化。当前重点完善两个已有工具：autoscript（自动化脚本）和 python-ai-operate（Python AI操作框架）。makemoney 项目尚未启动，需要明确启动条件。同时评估 Hermes 工具是否值得引入，提升整体工作流效率。

## 核心任务

| 工具名称 | 当前状态 | 下一步 |
|---|---|---|
| **autoscript** | 完善中 | 明确核心功能边界，补全常用场景脚本 |
| **python-ai-operate** | 完善中 | 梳理API与使用文档，跑通典型工作流 |
| **makemoney** | 未启动 | 明确项目目标与启动条件，先做最小验证 |
| **Hermes** | 待评估 | 调研功能与适用场景，判断是否值得引入 |

## 关键动作

1. 列出每个工具的待办功能清单，按优先级排序
2. 每周固定投入时间推进工具开发，避免工具建设挤占主业时间
3. makemoney 先做一周调研，判断是否值得启动，不盲目开工
4. 整理工具使用文档，方便自己日后回顾和复用
