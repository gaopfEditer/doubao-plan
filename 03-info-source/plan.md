# 项目03 · 信息来源

> **项目定位：** 建立高质量信息源体系，向需求发现与币圈优质情报转化；重点跟踪GitHub与推特头部账号，过滤闲杂噪音。

## 项目概述

构建高效、低噪音的信息输入渠道。核心目标是把零散信息源转化为可用于需求发掘和交易决策的优质情报。重点聚焦GitHub开源项目动态和推特（X）行业头部人物发言，建立筛选机制，只跟真正有价值的头部信息源，避免被闲杂信息淹没注意力。

## 核心任务

| 信息渠道 | 跟踪对象 | 关注重点 |
|---|---|---|
| **GitHub** | 头部开源项目、核心开发者、高星仓库 | 新项目趋势、技术方向、工具机会 |
| **推特/X** | 行业KOL、项目创始人、顶级投资人 | 早期信号、情绪变化、重要公告 |
| **币圈情报** | 优质研报、链上数据平台、头部资讯源 | 解锁预期、资金流向、板块轮动 |

## 关键动作

1. 梳理并分级信息源清单：S级（每日必看）、A级（每周扫一遍）、B级（按需查阅）
2. 建立信息过滤规则，过滤掉重复转载、无信息量的闲杂账号
3. 设计信息转化流程：优质信息 → 记录到需求池 → 评估是否可做产品/交易
4. 定期（每月）复盘信息源质量，淘汰低价值源，补充新发现的优质源
